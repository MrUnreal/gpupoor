# GPU Poor

Running large language models on one desktop CPU, measured carefully, written up with jokes. Every post ends with a receipt of its numbers.

Live site: https://mrunreal.github.io/gpupoor/

- `_posts/` — the posts (Jekyll)
- `FACTS.md` — the ledger every number comes from
- `SERIES.md` — what is published, what is next
- `CLAUDE.md` — how posts are written, fact-checked and published

Built by GitHub Actions (`.github/workflows/pages.yml`) with Jekyll on every push to `main`.
